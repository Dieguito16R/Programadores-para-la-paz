Sistema operativo:
Es el software principal que administra los recursos del computador y permite ejecutar aplicaciones y servicios.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript en el servidor.

Aplicación server.js:
Es el archivo que contiene el código del servidor y define cómo responder a las solicitudes de los usuarios.

Puerto:
Es un punto de comunicación utilizado por el servidor para recibir solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que almacenan eventos, mensajes y errores del sistema para facilitar el monitoreo y la solución de problemas.
